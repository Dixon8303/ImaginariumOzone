# Sample Deliverable — Context & Disclaimer

**SAMPLE — fictional organization. Every page in this folder describes a
fictional nonprofit, "Rise & Read Watts," built to demonstrate the Watts
Grant Studio process end to end. No such organization exists, no
application described here has been submitted to any funder, and no
partnership with any real school is implied.**

## What this is

This is the founder's proof asset: a complete, submission-quality grant
application package, produced by running a fictional organization through
the exact pipeline in `../pipeline/` — intake, extraction, drafting,
mandatory self-check, and packaging — against a **real, currently
operating California funding program.**

## The real funding opportunity used for this sample

**Program:** 21st Century Community Learning Centers (21st CCLC),
Elementary/Middle grant program
**Administering agency:** California Department of Education, Expanded
Learning Division
**Structure referenced:** the program's real, published evaluation
framework — the **12 Quality Standards for Expanded Learning in
California** (developed by the CDE Expanded Learning Division with the
California AfterSchool Network) — which the actual RFA narrative
questions and scoring rubric are aligned to, and the program's real,
published review structure: a 3-level screening process in which Level 1
is a holistic pass/fail quality assessment against those 12 standards,
requiring a rating of "Sufficient," "Comprehensive," or "Outstanding" on
each to advance.
**Timing:** CDE's Expanded Learning Division has indicated the next
competitive cycle (referred to publicly as "Cohort 16") is anticipated to
release in **August 2026** with an **October 2026** due date — which is
why this is the live opportunity Watts Grant Studio is building toward
right now, in July 2026.

## What is real vs. modeled in this sample

| Element | Status |
|---|---|
| Funder, program name, administering agency | Real |
| 12 Quality Standards for Expanded Learning in California | Real, published framework |
| Holistic pass/fail scoring by standard, "Sufficient / Comprehensive / Outstanding" tiers | Real, as described in CDE's public materials on the RFA process |
| 3-level screening structure | Real, as described in CDE's public materials |
| Exact per-question point allocations, page/word limits, specific narrative prompt wording | **Modeled** on the most recently released cycle's public structure, since the Cohort 16 RFA itself has not yet been published as of this sample's creation. Flagged `[MODELED — CONFIRM AT RELEASE]` throughout the requirements matrix. |
| "Rise & Read Watts" and all of its data, staff, sites, and outcomes | **Entirely fictional** |

This mirrors exactly how `pipeline/02_extract.md` instructs the studio to
handle a not-yet-released RFP: build the matrix from the most recently
published structure, flag every modeled row, and re-confirm against the
live document the moment it's released — before the self-check gate,
never after.
