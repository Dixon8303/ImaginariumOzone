# Seven-Day Launch Plan

Max 1 hour/day. The goal is not to do everything at once — it's to send
real messages, get real replies, and book the first $750 trial job.

## Day 1 — Review

- Read the sample deliverable (`sample/`) start to finish. Check every
  section sounds like you — the needs statement, the program narrative
  voice, the founder paragraph in `08_organizational_capacity.md`.
  Correct anything that reads off-voice before it becomes the proof asset
  you send to strangers.
- Read `site/index.html` in a browser. Same check: does the founder
  paragraph sound like you, is the price right, is the email correct.
- Fix what needs fixing. Nothing else today.

## Day 2 — Send messages 1–2

- Send outreach message 1 (Watts of Power Foundation leadership) and
  message 2 (fellow Teaching Fellow cohort member) from
  `outreach/messages.md`, with real names filled in.
- Note the date sent for each, so Day 4's follow-up has a clock to work
  from.

## Day 3 — Send messages 3–5

- Send outreach messages 3, 4, and 5 (partner nonprofit, arts-education
  contact, podcast-network contact), real names filled in.
- Same note-the-date discipline as Day 2.

## Day 4 — Follow-ups + prospect list

- For any of messages 1–3 with no reply after 2 days, send one short,
  friendly follow-up — not a new pitch, just a bump.
- Build a list of 10 more South LA education CBOs using Cause IQ or
  GuideStar: name, contact person if findable, mission area, approximate
  budget size (target the same $100K–$2M range). This is the list Day 5's
  cold messages go to.

## Day 5 — Send 5 cold variants

- Using the same honesty and structure as `outreach/messages.md` (one
  ask, one trial price, one yes/no question), send a cold version to 5
  organizations from Day 4's list. No warm connection needed — the
  message stands on its own because it's specific and low-risk (a $750
  trial, not a commitment).

## Day 6 — Intake-call script

- Write a short script for the first call with anyone who says yes:
  confirm they have a real, live RFP/NOFO with a real deadline; walk
  through `pipeline/01_intake.md` line by line so nothing is missed; set
  expectations on price ($750 trial), timeline, and what "self-scored
  ≥90%, zero unmet requirements" means in practice.

## Day 7 — Review replies, book the trial

- Review every reply across all 10 messages sent this week.
- For anyone interested, run the Day 6 intake call.
- Book the first $750 trial job — confirmed RFP, confirmed deadline,
  confirmed intake documents in hand — and start `pipeline/01_intake.md`
  for real.
