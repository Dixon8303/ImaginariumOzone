Black Genius Files Content Engine

A private, single-user tool for scheduling promotional Pins to its operator's own Pinterest boards.

Scope in one line. One operator, one Pinterest account, first-party content only — approximately one Pin per day promoting books the operator wrote and published. Not a product. Not a service. No third-party users.

What It Does

Black Genius Files is an independent publishing and documentary project by E.A.T. Media, preserving and retelling overlooked Black history. The project self-publishes two book collections — one poetry, one history. The Content Engine is a small script that saves the operator from manually uploading the same promotional graphics to Pinterest every day.

Each day the script selects one pre-approved book graphic and caption from a local library, and publishes it as a Pin to one of the operator's own Pinterest boards, linking back to the operator's own book pages.

How It Works

AuthenticationOAuth 2.0 authorization code flow against a single Pinterest account — the operator's own. No password collection, no session cookies, no credential storage on behalf of anyone else.
Scopes requestedboards:read, boards:write, pins:read, pins:write
Why each scopeboards:read — resolve the operator's own board IDs. boards:write — create or update the operator's own promotional boards. pins:write — publish the daily Pin. pins:read — confirm the Pin published and prevent duplicates.
VolumeApproximately 1 Pin per day; roughly 30–40 API calls per day total, well inside trial rate limits.
Content sourceOriginal artwork and copy for books authored and owned by the operator. No scraped, licensed, or third-party content.
HostingRuns locally on the operator's own machine on a daily schedule. No public endpoint, no multi-tenant infrastructure.
