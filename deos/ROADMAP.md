# Repository & Specification Roadmap

This roadmap defines the transition from discovery specifications (`v0.x`) to implementation engines (`v1.x` through `v6.x`).

---

## Phase 0: Discovery & Engineering Blueprint (v0.1 - v1.0)
> **Goal:** Complete a 100% deterministic, zero-ambiguity engineering specification before writing simulation runtime code.

- [x] **v0.1 Vision & Foundation**: Project scope, glossary, principles, success criteria.
- [x] **v0.2 Universal Laws**: Physical, energy, and information axioms.
- [x] **v0.3 Simulation Mathematics**: Q32.32 math, flux/progress formulations, PRNG model.
- [x] **v0.4 System Architecture**: Subsystem boundaries, messaging, Kernel/Host interface.
- [x] **v0.5 Entity Model**: 64-bit DOD entity layout and component storage.
- [x] **v0.6 Simulation Loop**: Tick sequence, double buffering, multithreading ordering.
- [x] **v0.7 Data & Memory Spec**: Memory layout, chunk allocation, zero-GC rules.
- [x] **v0.8 Prototype Specification**: Minimum Viable Simulation (MVS) baseline.
- [x] **v0.9 Specification Validation**: Traceability matrix, consistency tests, dependency audits.
- [x] **v1.0 Foundation Specification Complete**: Approved architectural blueprint.
