# Versions are MINIMUMS, not exact pins.
#
# An exact pin breaks the install outright once macOS/Homebrew upgrades Python
# past the last release that shipped a prebuilt wheel for that version: pip
# falls back to compiling from source and fails. That is what happened with
# Pillow==10.3.0 on Python 3.13 — and because pip aborts the whole run on the
# first failure, every package after it silently went uninstalled too, which
# is why the app reported missing modules that were "already in requirements".
#
# Floors keep the install reproducible enough while letting pip choose a build
# that actually works on whatever Python is present.
