Privacy Policy — E.A.T. Media Pin Publisher

Last updated: October 3, 2026

Overview

The E.A.T. Media Pin Publisher is a private, single-user application operated by E.A.T. Media. It connects one Pinterest business account (the account of the app's owner) to the Pinterest API in order to publish pre-approved book marketing graphics to boards owned by that same account. The application has no third-party users and is not offered as a service to any other person or business.

What the Application Accesses

  • The application requests only the permissions needed for its function: read access to the owner's own boards (boards:read), write access to create Pins on the owner's own boards (pins:write), and basic account identification (user_accounts:read).
  • The application creates Pins containing images, titles, descriptions, and links to E.A.T. Media's own published works and product pages.

Data Collection and Storage

  • The application collects no personal data from any Pinterest user other than the app owner's own account.
  • OAuth access and refresh tokens are stored securely on the app owner's private automation platform and are never shared, published, or transferred to any third party.
  • The application does not read, store, or process Pins, boards, or profile data belonging to any Pinterest user other than the owner.
  • No analytics, tracking pixels, cookies, or advertising identifiers are used by the application.

Data Sharing

The application does not sell, rent, trade, or share any data with any third party. No data is used for advertising or profiling.

Data Retention

The only data retained is the OAuth token required to keep the publishing connection active, and an internal log of Pins the application has published (image name, date, destination link). This log is private to E.A.T. Media and used solely to avoid duplicate posts.

Your Rights

Because the application accesses only its owner's own account and content, no other Pinterest user's data is processed. If you believe your data has been affected by this application, contact E.A.T. Media via eatmediatv.com and we will investigate and respond promptly.

Pinterest Developer Terms

This application complies with the Pinterest Developer Guidelines and the Pinterest Developer and API Terms of Service. It accesses the Pinterest API exclusively through the official OAuth 2.0 authorization flow.
